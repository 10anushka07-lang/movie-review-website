# Movie Search & Review Web Application

A responsive movie search web application built using HTML, CSS, JavaScript, and the TMDB API. The application allows users to search for movies and view detailed information including posters, ratings, and movie overviews.

## Features

* Search movies by title
* Fetch real-time movie data using TMDB API
* Display movie posters dynamically
* Show movie ratings with color-coded indicators
* View movie descriptions and overviews
* Responsive user interface
* Dynamic content rendering using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* TMDB API
* Fetch API

## How It Works

1. The application loads popular movies from TMDB API.
2. Users can search for any movie using the search bar.
3. The application sends an API request using Fetch API.
4. Movie information is displayed dynamically using DOM manipulation.
5. Ratings are highlighted using different colors based on score.
